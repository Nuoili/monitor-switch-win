Monitor Switch  显示器信号源一键切换  v2.4.0
==================================================

Windows 端常驻系统托盘：点托盘图标就能切信号源，不用开窗口、不用找文件夹。


■ Windows（已经装好，可直接用）

  程序：Monitor Switch.exe（只有一个文件，绿色免安装）

  运行后任务栏右下角出现一个显示器图标（两个蓝绿色方块叠在一起）。
  看不见就点托盘左边的 ^ 展开，那里能把它拖到外面固定住。

  · 左键单击图标     打开主窗口
  · 右键单击图标     弹出菜单：

        切到 Mac（HDMI-1）          → 显示器跳去 Mac 画面
        切回 Windows（DisplayPort）  → 显示器跳回 Windows 画面
        热键 Ctrl+Alt+Shift+D · 来回切   ← 灰字，告诉你当前热键是什么
        ─────────────
        显示主窗口
        开机时自动切回 Windows       ← 前面的勾表示已开启，点一下切换
        ─────────────
        退出                        ← 真退出，托盘图标消失

  关窗口 ≠ 退出
    点窗口右上角的 × 只是收进托盘，程序继续待着。
    想彻底退出，用托盘菜单里的「退出」。

  切完自动收起
    在主窗口里点了切换按钮并且成功，窗口会自动收回托盘，不用手动关。

  重复双击图标 = 唤起，不是再开一个
    程序已经在跑（不管窗口是收在托盘、最小化了、还是切信号源时自动收起了），
    再双击图标只会把原来那个窗口叫到最前面来，不会再开第二个窗口、第二个托盘图标。
    开机自启（--tray）那条是完全静默的，不会弹窗。

  开机自启
    托盘菜单 →「开机时自动切回 Windows」打勾即可。
    开机后先静默切回 Windows，然后常驻托盘。
    取消勾选就关闭。

  原理：DDC/CI（VCP 0x60）直接命令显示器换输入源，和按显示器上的按键等效，
        但不用手伸到显示器后面。


■ 热键（v2.3.1 新增）

  默认  Ctrl + Alt + Shift + D      按一下切走，再按一下切回来

  做成「来回切」而不是单向：切到 Mac 之后这台 Windows 就黑屏了，鼠标键盘
  够不到任何按钮 —— 这时唯一还能用的入口就是热键本身。所以摸黑按一下也能
  切回 Windows，这是热键最值钱的地方。

  为什么用三个修饰键：Windows 上两修饰的组合基本被占满了。
    · Ctrl+Alt+F1~F12  → Intel 核显图形热键
    · Ctrl+Alt+A       → QQ 截图
    · Alt+Z / Alt+R    → NVIDIA GeForce Experience
    · Ctrl+Shift       → 输入法切换
    · Alt+Shift        → 键盘布局切换
    · Win + 任何键     → 全归系统（Win+D/E/R/L/P/S/方向键…）
  再加一个 Shift 之后基本不会撞车。牺牲的是要按三根手指，换来的是按了必响。

  被占用会自动顺延
    程序内置 5 个候选，启动时按顺序试，第一个注册成功的才生效：
        Ctrl+Alt+Shift+D → Ctrl+Alt+Shift+M → Ctrl+Alt+Shift+F9
        → Ctrl+Alt+Shift+F10 → Ctrl+Shift+F9
    托盘右键菜单里那行灰字显示就是当前实际在用的组合。
    五个全被占的话，托盘会弹一个提示，右键菜单照样能切。

  换成自己顺手的
      Monitor Switch.exe --set-hotkey Ctrl+Alt+Shift+F9
    要求：至少一个修饰键 + 一个主键，中间不能有空格。
    修饰键可用 Ctrl / Alt / Shift / Win。
    程序正在跑的话会立刻换绑，不用重启。

  看当前用的是哪个
      Monitor Switch.exe --hotkey

  临时关掉热键（比如和某个游戏冲突）
      Monitor Switch.exe --no-hotkey

  热键配置存在注册表 HKCU\Software\Monitor Switch\Hotkey，卸载器会一并清掉。


■ macOS（需要先装一次 m1ddc，之后永久可用）

  把整个 macOS 文件夹拖到 Mac 上，然后在「终端」里执行一次：

      chmod +x ~/Desktop/Monitor Switch/macOS/*.command

  （路径按你实际存放位置改）

  然后按顺序双击：

    0-安装m1ddc.command      一次性安装，需要联网，约 1-3 分钟
                             （如果提示装 Xcode 命令行工具，点安装，装完再运行一次）
    1-切到Windows.command    切到 DP（看 Windows 画面）
    2-切到Mac.command        切到 HDMI（看 Mac 画面）
    3-设置开机自启.command    登录后自动切到 Mac 画面

  卸载开机自启：
    删除 ~/Library/LaunchAgents/com.monswitch.autostart.plist


■ 常见问题

  Q: 托盘里找不到图标？
  A: 1) 先点任务栏托盘的 ^ 看是不是收进溢出区了，拖出来即可
     2) 资源管理器重启过的话，程序会自动把图标补回去
     3) 还是没有就重新双击一次 Monitor Switch.exe

  Q: 点了菜单里的切换没反应？
  A: 显示器没响应 DDC 命令。检查显示器 OSD 菜单里的「DDC/CI」是否开启。
     AOC Q24G2 默认是开的，不用改。

  Q: Windows 上切换后屏幕黑了？
  A: 目标那台机器没开机或没输出信号。再点「切回 Windows」即可。

  Q: Mac 上切不过去？
  A: 如果 Mac 是通过拓展坞的 HDMI 接到显示器，个别拓展坞不透传 DDC 通道。
     这时把 Mac 那根线直接插显示器（或用 USB-C 转 HDMI 线直连）即可。

  Q: 托盘图标和我右键菜单里点的不一样？
  A: 菜单是每次点击时现读的，含开机自启的勾选状态，不会有缓存错位。

  Q: 热键按了没反应？
  A: 1) 右键托盘菜单看那行灰字，是不是显示「热键未启用」
     2) 如果被别的软件抢先占用，用 --set-hotkey 换一个组合
     3) 以管理员身份运行的程序（任务管理器、部分游戏）会挡住普通程序的热键，
        切到桌面再按即可

  Q: 热键和某个软件冲突？
  A: Monitor Switch.exe --set-hotkey Ctrl+Alt+Shift+F9 换一个，
     或用 --no-hotkey 临时停用（托盘菜单照样能切）。


■ 技术参数（AOC Q24G2 实测）

    DisplayPort = 15
    HDMI-1      = 17
    HDMI-2      = 18


■ 命令行（给快捷方式 / 计划任务用）

    Monitor Switch.exe                 打开主窗口
    Monitor Switch.exe --tray          直接进托盘，不弹窗口
    Monitor Switch.exe --auto --tray   先静默切回 Windows，再进托盘（开机自启用的就是这条）
    Monitor Switch.exe --mac           静默切到 HDMI-1，执行完退出
    Monitor Switch.exe --dp            静默切到 DisplayPort，执行完退出
    Monitor Switch.exe --state         打印当前信号源，不弹窗
    Monitor Switch.exe --version       看版本号
    Monitor Switch.exe --hotkey        看当前热键和候选顺序
    Monitor Switch.exe --set-hotkey X  改热键，X 形如 Ctrl+Alt+Shift+F9（会弹窗确认）
    Monitor Switch.exe --no-hotkey     本次不注册热键（排查热键冲突用）


■ 切回 Mac 时黑屏 / 显示器报「无信号」

  不是程序坏了，是显示器长时间停在 DP 后会锁存「无信号」，
  而 Mac 那边以为外接屏一切正常，不会重新协商，两边僵住。

  完整排查与三套方案看同目录：

      Mac端-HDMI黑屏修复.md        ← 直接投给 Mac 上的 AI 就行
      Mac端-三套方案.zip           ← 里面的 macOS 文件夹拷到 Mac 桌面

  Windows 这边已经配合好了：点「切到 Mac」时会先给 Mac 发一个 UDP 唤醒包
  （端口 9998），Mac 端装上监听之后就会在切换前重新协商一次显示输出。

  如果 Mac 端日志里收不到包，在本目录建 mac_ip.txt 写上 Mac 的局域网 IP。


■ 卸载

  双击同目录的「卸载器.bat」，按提示输入 Y。它会：
    1. 结束正在运行的 Monitor Switch.exe
    2. 删掉开机自启项（注册表 Run\Monitor Switch）
    3. 清理 %TEMP%\Monitor Switch 里的错误日志
    4. 打开本文件夹并选中，你把它整个拖进回收站就行

  最后一步故意留给你手动拖：脚本删不掉自己所在的文件夹，
  硬删又会被杀毒软件误判成木马。源码在
  github.com/Nuoili/monitor-switch-win，随时能重新 clone。

  不想要托盘图标了但想留着程序：托盘右键 → 退出 即可。
